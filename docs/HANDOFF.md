## 样式与布局

`tokens.css` 将 `/` 分组映射为 CSS 变量名的 `-`，保留语义 alias，不按相同颜色合并 token。`style.css` 使用 `base → utilities → components → screens → motion` 分层；`flex`、`items-center`、`gap-s` 等工具类可组合，组件状态采用变体类及 aria 属性。

字体优先加载包含当前界面字形的轻量 WOFF2 子集，保留完整字体作为任意故事文字的后备，不要求平板安装字体。`font-subsets.css` 的 Unicode 范围需在新增大量界面文案后重新生成；未包含字形仍可由完整字体正常显示。

1920×1080 下 `1rem = 16px`，根字号受视口宽高共同约束。页面主体使用 Flex/Grid 分配剩余空间，4:3 时增加内容高度并局部调整地图；没有对整个 DOM 使用 transform 缩小。地图、人物、贴纸在各自局部坐标系定位。贴纸使用归一化坐标，pointer 坐标依据当前画布的 DOMRect 反算；不用设计稿像素直接处理触摸。

对话、要素、故事正文、贴纸网格、电影列表各自滚动；操作按钮留在各自容器内。竖屏只提示横过设备，没有新增竖屏手机版布局。

## 演示规则（都不是正式业务契约）

- 资源种子：颜料 6，宝石 2；收藏 21/34，地图 2/15 独立维护。
- `demoConfig` 集中描述贴纸成本 1 颜料、电影成本 1 宝石、结算 +3 颜料、日领 +5、演示达标与时长。
- 初始两个故事片段用于还原当前叙事示例；继续按住说话会补充地点、原因、结局。演示达标与是否满星分开，返回后仍可继续补充。
- “翻开故事本”为达标后的前端继续入口，避免使用 Figma 的 0.8 秒超时强制推进；未增加历史的双按钮方案。
- 生成只在接受结果时扣费，重试/关闭不扣；同一 requestId 不会重复扣费。
- 同一故事 session 只收一次拍摄费用，返回编辑重试不重复扣；结算使用 session 事务标记，只奖励一次，重复播放动画不影响余额。
- 日领使用 Asia/Shanghai 本地日期，仅在此浏览器保存，不是账号签到。
- 收藏保留当前设计的重复彩虹占位。新生成的演示贴纸有独立 ID，追加到收藏，收藏分母随扩展变化。
- 电影使用分层舞台、男孩、小猫、风筝与用户贴纸。选场景、贴纸、正文写入作品快照。三名演员为当前 Figma 的示例演出阵容；编剧/选角/镜头规划仍属于 mock。
- 演示拍摄约 8 秒，预览 16 秒，图鉴播放器 32 秒；播放结束才到结算，点第四幕只是定位。
- 配音选项演示进入/结束配音与保存选项，不录制真实声音，也不播放真实配音。
- “问问爸爸妈妈”和兑换没有定义接口，目前给出明确演示反馈。

## 动效

页面过渡 0.3 秒；按钮压下、选中、贴纸弹入、麦克风波纹、岛屿 105% 脉冲、书脊展开、演员/风筝局部运动均由 CSS 驱动。可点击容器本身保持稳定，循环动画放在内部视觉层。

结算按当前 8 秒序列安排：中星 0s，左星 0.739s，右星 1.190s；保存 3s，返回 3.38s；宝箱 4.004s 起退出；新贴纸 4.423s 弹入；颜料 4.544s 显示、5.720s 起飞出；标签 5.496s，目标 5.970s。账务由 reducer 的幂等事件完成，与动画回调无关。

`prefers-reduced-motion` 会跳过非必要动画并直接显示最终内容。离开页面会清理媒体、录音和生成计时器；麦克风支持 pointercancel、失焦与键盘操作。
